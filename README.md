# Employee Management System - Backend

A RESTful backend application for managing employee records, built using Java, Spring Boot, Spring Data JPA, Hibernate, and MySQL.

This backend provides APIs for creating, reading, updating, and deleting employee records and is integrated with a React.js frontend.

## Features

- Employee CRUD operations
- RESTful APIs
- MySQL database integration
- Spring Data JPA
- Hibernate ORM
- Jakarta Bean Validation
- Global exception handling
- Employee not-found handling
- CORS configuration for React frontend
- Maven-based project
- Environment variable for database password
